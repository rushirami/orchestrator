# Local environments

This fork runs on your computer. The local environment settings include its icon
and, on Windows, the WSL backend and distro selection. Changing the primary WSL
backend may restart the app; the confirmation explains the effect on open work.

Network exposure, Tailscale, pairing links, client access management, and adding
remote backends are no longer available in Settings.

The app opens only local environments. It no longer restores saved remote servers or accepts pairing
links. Existing projects and conversation history remain on the machine that owns them. Provider,
pricing, theme, usage, and source-control integrations remain available.
